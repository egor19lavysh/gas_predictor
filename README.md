Это мой проект для мероприятия от Газпрома совместно с ВШЭ "Зайти в Айти" на тему решения задачи прогнозирования краткосрочного потребления газа (от 1 до 7 дней) в регионах России (63 шт.) на синтетических данных (минимально отличаются от настоящих данных по словам авторов задачи) за несколько лет по температуре, потреблению газа (в кубометрах) и типу дня (обычный рабочий, сокращенный, выходной, праздничный).
Написано 4 модели: линейная регрессия (используется в боевом режиме приложения), prophet, sarimax и lstm. 
Интерфейс приложения реализован с помощью библиотеки streamlit.
